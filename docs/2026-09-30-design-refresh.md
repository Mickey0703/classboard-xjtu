# 班务界面视觉升级

面向 ID 2601 同学和班委，核心目标是快速看见重要通知、确认待办和维护班级事项。

参考来源：Linear（https://linear.app/）、Notion（https://www.notion.com/product）与 Apple 教育页面（https://www.apple.com/education/）。这些网站用于视觉调研；本项目自行实现布局、样式和组件。

设计采用西交大红 #991e32、班徽深蓝 #08254d、浅灰页面 #f5f6f8、白色内容面板和细边框 #e7e9ee。桌面导航放在品牌顶栏，手机使用浮动底部导航。首页合并班级标识与欢迎区，通知列表成为主栏，日程和天气成为辅助栏。通知页使用较安静的标题区、分段筛选与清晰状态；班委表单采用统一标签、间距和操作样式。

使用系统字体以保证中文渲染和加载稳定；没有新增外部字体依赖。仅保留短暂的悬停反馈，支持键盘焦点和减少动态效果偏好。已检查 1280、390、320 像素宽度的横向溢出。

功能沿用已有身份、发布、知悉、完成和统计接口。课表和论坛仍不在网站范围内。

# 西安交通大学班务系统：第一阶段设计

日期：2026-09-28

## 目标与范围

为一个西安交通大学班级建立公开可读、由班委维护的班务网站。第一阶段实现首页、课表和日程，视觉布局和主要交互参考“柚子社”公开网站；论坛、通知及普通同学账户留待后续阶段。网站使用本班自有文字、课程、事项与素材，不复制参考站的班级数据和校徽文件。

## 用户与权限

- 访客无需登录，可查看课程、日程和首页摘要。
- 班委登录后可新增、编辑、删除课程与日程事项。
- 编辑权限由服务端验证。前端不保存可写数据库的密钥。
- 公开内容只放适合公开的信息；不在课表或事项中填写个人联系方式、学号等隐私数据。

## 页面与交互

### 首页

保留参考站的卡片式内容和移动端底部导航语言；顶部采用西安交大标志性的红色，搭配西交大主题、名称和自行制作的标识。首页展示今日日期、课程数、当前或下一节课、天气、近期事项、今日时间轴及本周课表入口。摘要均由课程和事项数据计算，不分别维护。天气使用西安位置的公开天气接口；接口不可用时显示明确的“天气暂不可用”，不展示旧数据冒充实时天气。

### 课表

按学期起始日期计算教学周，展示周一至周日课程。支持上周、本周、下周切换；课程详情包含名称、教师、地点、星期、节次、开始和结束时间、起止周及单双周规则。课程能由班委编辑，并可导出当前课表为 `.ics` 文件。无课或超出学期范围时显示清楚的空状态。

### 日程

展示近期事项和按日期浏览的列表。事项包含标题、描述、开始时间、截止时间、类别及状态；自动标识即将截止和已过期。班委可在管理页增删改，普通访客只能查看。时间均按 Asia/Shanghai 解释和显示。

### 班委管理页

独立的登录与编辑界面，维护课程、学期设置和日程事项。保存前进行字段校验，保存后公开页面读取到新数据。编辑失败保留输入并提示具体原因。第一阶段不提供论坛发帖或通知推送。

## 技术与数据流

推荐 Cloudflare Pages 托管前端，Pages Functions 提供公开读取及需登录的写入接口，D1 保存共享数据。课程、事项和学期设置存储在独立表中，接口返回结构化数据；首页、课表和日程复用同一数据源。公开读取接口只返回必要字段。班委登录使用 Cloudflare Access 的邮件白名单，管理接口在服务端验证 Access 令牌与班委身份，写入前再次检查权限与输入；不自行保管班委密码。开发时使用本地 D1 数据；正式部署后绑定生产 D1。

前端将页面组件、数据请求和日期/课表计算分开，便于以后替换托管平台或增加论坛、通知。项目提供不含真实班级信息的示例数据，正式内容由班委录入。

## 托管与费用

截至 2026-09-28，Cloudflare Pages、Pages Functions 和 D1 均提供免费额度。Pages 免费计划包含每月 500 次构建；Workers 免费计划包含每天 100,000 次请求，Pages Functions 使用该额度；D1 免费计划包含每天 500 万行读取、10 万行写入和总计 5 GB 存储。Cloudflare Zero Trust 也有免费计划，但其开通流程可能要求录入付款资料，即使免费计划不收费。超过免费额度时相关请求可能失败，不能承诺无限量免费。GitHub Pages 可免费托管同一前端，但它只提供静态网页；若改用 GitHub Pages，仍须另外部署认证、接口和数据库。第一阶段选择 Cloudflare 方案以减少部署部件。域名如使用自购域名，注册费用另计。

## 验收

- 手机和桌面宽度下，首页、课表、日程均可用，布局与参考站的主要视觉结构接近；顶部以西安交大标志性的红色呈现，并明确呈现西交大身份。
- 教学周、单双周、跨周课程及下一节课计算正确；日历导出可被常见日历软件导入。
- 访客不能调用写入接口；班委登录后可完成课程和事项的增删改，刷新后数据仍在。
- 天气、数据库或网络异常时有明确反馈，不出现误导性的成功状态。
- 项目能在本地启动、运行必要验证，并提供部署和录入班级数据的说明。

## 待提供的真实资料

班级名称、学期开始日期与校历、作息时间、课程表、首批日程事项，以及允许作为班委管理员的账号。这些资料不阻碍使用示例数据开发和本地验收。
